# 已定行为

只记现行规则。改行为时同步修改这里。

## 提取

通用文字遍历加 GitHub、Reddit、X 的站点范围与阅读单元规则，默认只取主要内容，弹窗可勾选“包括导航等其他区域”。处理普通 DOM 和开放 Shadow DOM，不处理 iframe、封闭 Shadow DOM 和图片文字。

代码、文件名、表单和编辑器不作为独立翻译内容；段落里的代码、路径、链接、版本号、时刻和带单位的数字用 `<kN>` 标签原样保留，普通数字和年份作为正文交给模型并由提示词要求保持不变。行内链接和强调用 `<iN>` 标签，可随语序移动。

网页标为不翻译（`translate="no"` 或 `.notranslate`）的行内元素，如 GitHub 的行内代码和 @提及，同样作为 `<kN>` 留在句中，不把段落切开；块级的不翻译元素仍整块跳过。GitHub 文件表整张表是一个阅读单元。

## 语境

文档段落共用页面标题（去掉 “(3) ” 这类未读计数）作为 context；所在节标题作为该段的附注。X 引用帖、Reddit 父评论作为对应帖子的附注。同一批次里相同的附注只发送一次，各段按编号引用（notes）。不调用摘要模型，不附带随机邻段。

## 调度

- 当前屏优先，沿滚动方向预翻两到三屏，预加载最多 30 段、估算 4000 token、两个并发，让段落进屏前大多已翻好；快速划过时撤销未发出的任务。
- 首批最多 3 段或 400 估算 token，之后每批最多 6 段或 1200 估算 token，附注在预算里只计一次。
- 已是目标语言的段落在网页脚本里跳过，不进入批次和预加载预算：目标是中文或日文时先按文字判断（中文：汉字至少 4 个、不少于外文单词数的两倍、没有假名和谚文；日文：有假名且汉字加假名不少于外文单词数的两倍），否则用浏览器语言检测，检测不可靠时交给模型。
- 模型返回的文字与原文只差标点全半角和空白时，按原样保留处理，不显示为译文。
- 滚动时页面状态和任务计划没有变化就不发消息。
- 所有标签页共用后台一个队列，合计最多 10 个并发。

## 复用

- 同一 documentId 内切换路由，保留译文、页面缓存、会话、在途请求和本页用量；跨站停止翻译，新标签页默认关闭。
- 弹窗勾选“总是翻译此网站”后（按协议加主机名记录，单独申请该站点权限），该站点在任何标签页加载完成即自动开始；取消勾选后不再自动，已授予的站点权限保留，可在 Chrome 扩展详情里移除。
- 后台另有会话结果缓存（storage.session，只在内存，浏览器关闭即清空，最多 2000 条或约 3 MB，按最近使用淘汰，键是哈希，值只有译文）。同样的原文、语境、语言和接口设置在任何标签页、刷新后或重新打开时直接复用，不再请求模型，也不计入本页用量。保存设置时清空。
- 点“显示更多”时旧译文保留到全文译文回来。

## 请求

- 接口格式二选一：OpenAI 兼容的 Chat Completions，或 Anthropic 兼容的 Messages；模型 ID 由设置决定。
- 思考强度可选默认、关闭、低、中、高。“默认”不发送任何思考参数，由服务商决定；新设置默认为关闭。开启思考会推迟首段译文，也可能占满输出上限而正文为空；实测对译文没有改善。
- temperature 1.0，max_tokens 2048，流式返回并带用量统计，要求 JSON 输出（OpenAI 格式为 stream、include_usage 与 json_object）。
- 首段正文 15 秒、正文停滞 10 秒、总计 45 秒超时。
- 结构异常只修复缺失段落一次；标签偏差先在本地宽容修复；模型编造的 `<iN>`/`<kN>` 以外的标签去掉。
- 因长度截断而正文为空只算这批段落失败、可原地重试，其他空正文按配置错误暂停。
- 认证、配置、余额错误停止派发；429 暂停，等待手动继续；断流、超时、5xx 的未知结果不自动重发。未知用量不记零。

## 用量

本页用量在后台内存按 documentId 关联；最近 100 次请求的统计保存在 storage.local，不存正文、网址或 Key。

## 网页提示

- 正在等译文的段落末尾显示淡色闪烁的“⋯”，译文回来即消失；已显示旧译文的不加。
- 翻译失败的段落末尾显示“翻译失败 · 重试”，悬停可见错误原因，点击只重发这一段，并拦截点击不让网页自己的链接或帖子跳转。
- flex/grid 布局的段落不加这两种标记，仍可在弹窗里看到和重试。
- 仅看译文模式下，鼠标悬停译文段落约半秒，旁边浮出该段原文（不发请求，滚动或移开即隐藏）；双语模式不显示。
- 标记和浮窗都不参与提取、语境和帖子边界判断。

## 阅读位置

插入或撤下译文前记下视野上方约三分之一处正在读的段落，改完后把它上方增加的高度滚回去，这段在屏幕上不动；页面在最顶部时不补偿。同一帧到达的译文一起插入。新出现的译文约 0.2 秒淡入，已显示的（缓存、临时沿用）替换时不闪；系统开启减少动态效果时不淡入。

## 译文排版

双语模式下标题的译文为原标题的 0.78 倍大小，正文译文颜色为原文颜色的 74%；目标语言为中文或日文时，译文在网页字体后补上对应的中日文字体，行高不足 1.6 的放宽到 1.7，网页设置的字间距恢复正常。仅看译文模式只在网页元素只含这一段时调整其字体与行高，恢复时还原。

## 段落操作

- 鼠标停在已翻译段落上约 0.35 秒出现“原文 · 重译”，依次试段落右侧、右上方、右下方，选第一个只压在空白背景上的位置（不压段落自身文字、相邻侧栏或其他文字），都不行时放在段落右上方。
- 模型原样返回的段落（如人名）悬停时显示“原文已保留 · 重译”。
- 原文：这一段恢复原文、不再请求，再点“译文”切回，不发请求；关闭翻译后全部重置。
- 重译：保留当前译文直到新译文到达，只重发这一段并跳过已完成结果缓存。
- 操作条的点击不传给网页。

## 页面进度

有段落等待超过 0.6 秒时，页面右下角显示“翻译中 x / y 段”和进度线，全部完成后显示“已翻译 n 段”约 1.4 秒后消失；有失败时显示“n 段翻译失败”和“重试”“×”，直到重试或关闭。缓存直接完成的页面不显示。

## 弹窗

本页状态下方有进度条，失败时为红色；当前网站已开启自动翻译时，网址旁显示“自动翻译”。

## 版本不一致

扩展各入口在编译时带上版本号。弹窗、后台和网页脚本来自不同构建时（例如替换了已解压扩展的文件但旧后台仍在运行），弹窗提示“重新加载扩展”，网页脚本过旧时提示刷新网页；两种情况都不发模型请求。重新加载扩展保留已保存的设置和 Key。

## 译文风格

提示词要求按目标语言的自然说法翻译习语、俚语、网络缩写和文字游戏，不逐字直译；简短回复和感叹词也要翻译。提示词有版本号（参与缓存键），改提示词时更换版本号，旧缓存随之失效。
